## 本版变更

相对 0.8.7 只有一项修复，其余功能与 0.8.7 相同：

- **macOS：菜单栏图标默认改为紧凑样式，宽度封顶 4 个标记**（#29）。原来的默认「文字」样式随服务商数量无上限变宽（3 家约 307px、6 家约 653px），会把其他应用的菜单栏图标挤进刘海隐藏区。现在默认用「紧凑」样式，超过 4 家只显示最紧张的 4 家，宽度最多 81pt。
- **老用户一次性迁移**：升级后，已保存的「文字」样式会一次性改为「紧凑」。想要原来的样子，可在 设置 → 外观 → 图标样式 改回「文字」，改回后不会再被迁移。
- Windows 与 Linux 行为不变。

## 安装与更新

OpenQuota 提供 Windows 与 Linux 的 x64/ARM64 构建，以及 macOS Universal 构建。

自动更新使用加密签名。Linux 应用内更新适用于 AppImage；Debian 包通过软件包安装程序更新。
